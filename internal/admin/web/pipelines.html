Un pipeline IN lit une source (fichier envoyé ou déposé, adresse HTTP, serveur SFTP, base PostgreSQL) et écrit dans une donnée du Data Lake (créée d'après les données, ou existante) ou dans un tableau d'un classeur. Un pipeline OUT déverse une donnée ou un tableau vers l'extérieur, avec les mêmes protocoles. Chacun agit sous une identité technique « Pipeline : … ». Les secrets se saisissent en valeur : ils sont gardés chiffrés sur le serveur.
